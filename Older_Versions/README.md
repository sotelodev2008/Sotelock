## 🇬🇧 English

* [1.0](./1.0/README.md) - This was the first version to get uploaded to GitHub, it's very basic: the passwords are added via code into `dataclasses` in `strings`, so it is not very secure.
* [2.0](../README.md) - The newest version. Adds a `SQLite` database and brand new sarcastic quotes, as well as some custom error messages for exceptions like `KeyboardInterrupt`.

## 🇪🇸 Español

* [1.0](./1.0/README.md) - Esta fue la primera versión en ser subida a GitHub, es muy básica: las contraseñas se añaden por código dentro de `dataclasses` en texto plano, por lo que no es muy segura
* [2.0](../README.md) - La versión más reciente. Añade una base de datos `SQLite` y nuevas frases sarcásticas, además de mensajes personalizados para ciertos errores, como `KeyboardInterrupt`.
